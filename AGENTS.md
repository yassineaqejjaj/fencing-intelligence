# Agent guide

This repository is Fencing Intelligence, a self-hosted fencing video analysis platform. Original application code is Apache-2.0. Do not vendor code from datasets whose licenses are GPL-3.0, unspecified, or absent.

## Layout

- `apps/web` — Next.js App Router. The browser calls same-origin `/api/v1`, which rewrites to the API.
- `services/api` — FastAPI, SQLAlchemy, Alembic, auth, videos, annotations, statistics, reports.
- `services/video-worker` — FFmpeg probe and transcode. Production images install FFmpeg with apt. Local tests may use binaries on `PATH`.
- `services/ml-inference` — experimental movement and scoreboard heuristics. They do not claim recognition accuracy.
- `packages/fencing-domain` — weapon taxonomy, statistics formulas, coaching rules, dataset registry.
- `ml` — importers and an optional synthetic baseline. Do not download external datasets automatically.

## Rules that matter

- Statistics use validated annotations and validated valid touches only. A rate with a zero denominator is null, with reason `no_samples`. Do not draw a chart when `data_status` is not `ok`.
- Model suggestions stay `draft` until a person validates them. Scoreboard light candidates are unvalidated score events and do not change the bout score.
- Metric distance requires calibration. Otherwise return pixels.
- Private videos are authorized in the API. Return 404 for another organization's resources.
- Do not train on athlete video unless a consent record grants `research_training`.
- Do not copy FIE or FFE rulebook text into the taxonomy. Store short original labels and source URLs.
- `datasets doctor` reports missing, restricted, and incompatible datasets. Missing is the expected state until an operator places a local manifest.

## Local run

Postgres, Redis, and the S3-compatible server come from `docker compose up -d postgres redis minio`. Apply migrations from `services/api` with `.venv/bin/alembic upgrade head`. Start the API with `INLINE_JOBS=true` when no Dramatiq worker is running, and keep `ffmpeg` and `ffprobe` on `PATH`. Start the web app from `apps/web` with `pnpm dev`.

Tests live in `services/api/tests` and `packages/fencing-domain/tests`. They use database `fencing_test`, Redis database 1, and bucket `fencing-test`. Run them with the API virtualenv. Frontend unit tests are `pnpm test` in `apps/web`.

## Next.js

`apps/web/AGENTS.md` is generated by the Next.js toolchain. Read `node_modules/next/dist/docs/` before changing framework conventions. This Next.js version uses `LayoutProps` as a global helper.
